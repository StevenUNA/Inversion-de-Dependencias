# Inversion de Dependencias  

¿Cómo se implementan?  

Se crean clases derivadas y clases hijas para los productos y el envio de recibo  

La clase AdmProducto trabaja con las clases padres (Clases abastractas), por lo que no se ve restringida por las características de las clases hijas. Usan Punteros para llamar metodos propios de cada clase padre.  

Se trabaja entre clases abstractas
